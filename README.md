# 👨‍💼 Employee & Sales Analysis Dashboard

An end-to-end **Employee & Sales Analysis project** built using **Python, SQL, MySQL, Excel, and Power BI** to analyze workforce performance, employee salaries, sales, profit, product performance, departments, and regional trends.

The project transforms raw business data into interactive dashboards and actionable insights to support **data-driven decision making**.

---

# 📊 Project Overview

This project combines **HR Analytics** and **Sales Analytics** into a single business intelligence solution.

The analysis covers:

* Employee demographics
* Employee salaries
* Department performance
* Employee experience
* Sales performance
* Profit analysis
* Product performance
* Regional sales
* Business reporting
* KPI analysis

The complete workflow includes **data cleaning, SQL analysis, data modeling, DAX calculations, and Power BI visualization**.
